# Epidemiology catalog

The **Epidemiology catalog** brings together services for epidemic modeling, simulation, and interactive analysis of disease dynamics.

## Services available

### uc1-dashboard

Web dashboard service for UC1 - epidemiology.

This service provides an interactive web interface for exploring epidemic data and results in the UC1 workflow. It is intended to support monitoring, analysis, and visualization of epidemiological outputs through a browser-based dashboard.

### uc1-agents

Agent-based epidemic simulation model designed to study the dynamics of vector-borne diseases in spatially explicit environments.

This service supports epidemiological simulation using autonomous agents that model disease transmission and spatial interactions. It is designed to study vector-borne disease dynamics in structured environments and to generate insights into epidemic behavior under different scenarios.
