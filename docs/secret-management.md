# Secret management

SIESTA uses [Vault](https://vault.deployments.cloud.eosc-siesta.eu) for secret management. You can access this service directly from the dashboard's [**My Secrets**](https://dashboard.cloud.eosc-siesta.eu/my-secrets) section.
